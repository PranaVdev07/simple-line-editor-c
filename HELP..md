# Simple Line Editor - Help

## Commands

### Insert a Line

Syntax:

i <line_number> <text>

Example:

i 1 Hello World

This inserts a new line at the specified line number.

---

### Delete a Line

Syntax:

d <line_number>

Example:

d 2

This deletes the specified line.

---

### Display Document

Syntax:

p

Example:

p

Displays all lines with their line numbers.

---

### Help

Syntax:

h

Example:

h

Displays all available commands.

---

### Quit

Syntax:

q

Example:

q

Exits the line editor.
